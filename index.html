1. Project Objective

The primary objective of this project is to organize and rank a collection of movies based on their audience rating scores using the fundamental Bubble Sort algorithm.

In everyday platforms like IMDb, Netflix, and Rotten Tomatoes, users frequently sort titles by highest rating or lowest rating. This project bridges theoretical computer science and practical software design by showing how adjacent comparisons and element swapping work visually to achieve ordered data.

2. Theory & Concepts

📌 What is Sorting?

Sorting is the systematic process of arranging data elements in a specific order (either ascending or descending). In computer science, sorting improves search efficiency, makes data readable for humans, and optimizes subsequent operations like binary searching.

🫧 What is Bubble Sort?

Bubble Sort is an elementary, comparison-based sorting algorithm. It is called "Bubble Sort" because larger (or smaller) elements gradually "bubble up" to their correct final positions at the end of the collection with each passing iteration, much like air bubbles rising in water.

⚙️ How Bubble Sort Works

  1. Start at the very beginning of the array (index 0).
  2. Compare the current movie rating with the adjacent movie rating right next to it.
  3. If the two movies are in the wrong order according to the selected sorting rule (e.g. current < next for descending order), swap their positions.
  4. Advance one position to the right and compare the next adjacent pair.
  5. Repeat this process across all items. By the end of Pass 1, the largest (or smallest) element is guaranteed to be settled at the end.
  6. Execute subsequent passes, each time ignoring the elements that are already settled in previous passes.
  7. Stop when no swaps occur during an entire pass, indicating the list is fully sorted.

✅ Advantages

  • Easy to understand: Bubble Sort is simple to learn and implement, which makes it suitable for beginners.
  • Uses very little memory: It sorts the data in the same array without requiring extra memory, so its space complexity is O(1).
  • Stable Sorting: If two movies have the same rating, their original order is maintained.
  • Can detect sorted data quickly: With an optimized Bubble Sort using a swapped flag, the algorithm can finish in O(n) when the list is already sorted.

⚠️ Limitations

  • Not suitable for large datasets: Bubble Sort becomes slow as the number of movies increases because it can take O(n²) time.
  • Slower than advanced sorting algorithms: Algorithms such as Quick Sort and Merge Sort generally perform better for large datasets, with an average time complexity of O(n log n).
  • More swaps: Bubble Sort may perform many swaps while sorting, which can make it less efficient than algorithms such as Selection Sort.

🎬 Step-by-Step Example (Descending Order)

Consider three movies with ratings:

Initial State (Unsorted):

Movie A: 7.5
Movie B: 9.0
Movie C: 8.0
➡️

Pass 1 Operations:

Compare A (7.5) & B (9.0) → 7.5 < 9.0 → Swap! [B, A, C]
Compare A (7.5) & C (8.0) → 7.5 < 8.0 → Swap! [B, C, A]
➡️

Final State (Sorted):

1. Movie B: 9.0
2. Movie C: 8.0
3. Movie A: 7.5
